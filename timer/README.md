# シンプルタイマー

ブラウザだけで動作する、ビルド不要のカウントダウンタイマーです。

## 使い方

1. `timer/index.html` をブラウザで開く
2. 時・分・秒を入力して「スタート」を押す
3. 時間になるとビープ音が鳴り、表示が点滅します

## 機能

- カウントダウン表示（時・分・秒）
- スタート / 一時停止 / 再開 / リセット
- 完了時にビープ音
- ダークテーマのUI
- 依存ライブラリなし（HTML / CSS / Vanilla JS のみ）

## ファイル構成

- `index.html` — マークアップ
- `style.css` — スタイル
- `script.js` — タイマーロジック
