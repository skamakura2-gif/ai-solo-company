# REQUIREMENT: パーソナル目標・タスク管理アプリ

## 1. プロジェクトの目的
ユーザーの個人目標（定量的・定性的なOKRや評価フィードバック）を入力し、それを「月次」「週次」「日次」の具体的なタスクやルーティンに落とし込み、確実な実行と振り返りをサポート・管理するアプリケーション。

## 2. ターゲットユーザー
- 企業での目標（営業ノルマやコンピテンシー評価）を達成するために、自身の行動を逆算して日々管理したいビジネスパーソン。（特に言語化や習慣化を課題としている方）

## 3. コア機能要件

### A. 目標（OKR/課題）設定機能
- 半期や通期などの**「大目標（定性・定量）」**および**「フィードバック課題」**を登録できる機能。
  - *例：単月600万円の売上達成、即時レスポンス（1時間以内）の徹底、週次での課題言語化など。*

### B. 期間別タスク・アクション管理（日次 / 週次 / 月次）
- **日次（Daily）管理:**
  - 毎日のルーティンタスクのチェックリスト（例：「一次返信の徹底」「業務完了報告時の課題言語化」「明日のタスク逆算」）。
  - その日の成果や「できなかったこと」の簡単な振り返りメモ（日々の言語化トレーニング）。
- **週次（Weekly）管理:**
  - 週1回実行すべきタスクの管理（例：「営業課題の深掘り」「リーダー陣へのヒアリングと成果物提出」）。
  - 1週間のアクションの振り返りと、次週に向けた対策の記録。
- **月次（Monthly）管理:**
  - 月間KPIの進捗トラッキング（例：「単月600万円達成」「基準クリア学生数 4名」など）をプログレスバーなどで可視化。

### C. ペナルティ / モチベーション管理（ゲーミフィケーション）
- タスク未達時のペナルティ集計（例：「日次タスク未完了1項目につき100円のチーム貯金」などをカウントし可視化）。
- 完了の「連続達成記録（ストリーク）」などによる行動の定着支援。

## 4. UI/UXの要件
- **ダッシュボード:** 今日やるべき「日次タスク」、今週の「週次進捗」、今月の「KPI達成率」が1画面で俯瞰できること。
- **高速な入力:** 業務後や移動中にストレスなくサクッとタスクチェックとメモ（言語化）ができる、モバイル・スマホ対応（レスポンシブ）のUI。
- **デザインスタイル:** shadcn/ui をベースにした、モダンで視認性が高く洗練されたデザイン（ダークモード対応）。

## 5. 技術・インフラ（一人企業 Vibe Coding環境）
- **Frontend:** Next.js 15 (App Router), React 19, Tailwind CSS
- **Backend/Auth:** Supabase (Auth, PostgreSQL, RLS)
- **Deployment:** Vercel (予定)
